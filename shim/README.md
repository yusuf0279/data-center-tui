# data-center-tui has moved

This project is now called **build-a-hyperscaler**. This package contains no code: installing or upgrading it just installs `build-a-hyperscaler`, and provides the legacy `data-center-tui` command. Python code must now `import build_a_hyperscaler` instead of `data_center_tui`.

```
pipx install build-a-hyperscaler
build-a-hyperscaler
```

Source and issues: https://github.com/yusuf0279/data-center-tui
